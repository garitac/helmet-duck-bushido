# Security

Report Bushido vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/garitac/helmet-duck-bushido/security/advisories/new).
Reports may be submitted in English. Do not open a public issue for a security defect.

For the marketplace or helmetduck.com, use
[the marketplace's private reporting form](https://github.com/garitac/helmet-duck/security/advisories/new).
If you cannot use GitHub, contact hello@helmetduck.com. Do not send passwords,
access tokens, or private customer data with an initial report.
